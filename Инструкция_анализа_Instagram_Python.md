# Инструкция проекта Instagram Analytics на Python

## Файлы проекта

- Данные: `dataset/Instagram_Analytics.csv`.
- Исполняемый анализ: `Instagram_Engagement_Analysis.ipynb`.
- План слайдов и интерпретации: `План_презентации_Instagram.md`.
- Экспортируемые таблицы: `results/`.
- Экспортируемые графики: `results/figures/`.

## Запуск notebook

1. Откройте `Instagram_Engagement_Analysis.ipynb` в VS Code.
2. Выберите Python 3 kernel. При первом запуске может понадобиться установить пакеты из ячейки imports: `numpy`, `pandas`, `scipy`, `matplotlib`, `seaborn`, `statsmodels`, `scikit-learn`, `ipython`.
3. Убедитесь, что `dataset/Instagram_Analytics.csv` лежит в этой же папке проекта. Notebook ищет CSV относительно текущей папки и завершится понятной ошибкой, если файл не найден.
4. Выполните все ячейки сверху вниз через **Run All**. Ячейки с тестами зависят от результатов EDA и подготовки данных.
5. Последняя ячейка сохранит итоговые CSV и PNG-графики в `results/`.

## Что проверяет анализ

1. Схему, число строк, пропуски, дубликаты `post_id`, даты и категории.
2. Частоты, описательную статистику, гистограммы и boxplot `engagement_rate`.
3. Различия между форматами: Levene, обычная ANOVA, Welch ANOVA, Kruskal–Wallis и попарные Welch t-тесты с поправкой Holm.
4. Spearman/Pearson для охвата, показов, реакций, длины подписи и хэштегов; корреляции охвата/реакций с целевой метрикой помечены как исследовательские из-за неизвестной формулы engagement rate.
5. Нелинейность длины подписи и числа хэштегов через квадратичные члены и робастный Wald-тест.
6. Таблицу `media_type × engagement_level`, χ² независимости, V Крамера, ожидаемые частоты и составную диаграмму.
7. Прогноз: медианный baseline, линейная регрессия и Random Forest; хронологическое разделение по целым датам; метрики R², MAE, RMSE на отложенной выборке.
8. K-Means на логарифмированных метриках реакций/охвата, подбор k по silhouette, профили и PCA-визуализацию.

## Методические правила для презентации

- Формула и единицы `engagement_rate` не опубликованы. Не добавляйте знак `%` без подтверждения.
- ANOVA проводится на `log(1 + engagement_rate)` из-за сильной асимметрии; исходную метрику также показывайте описательно.
- Для сравнения четырёх форматов используйте глобальный ANOVA/Welch, а не серию независимых t-тестов без поправки.
- Публикационные взаимодействия не образуют граф пользователей: не делайте выводов об инфлюенсерах, ботовых сетях или распространении между аккаунтами.
- В регрессию не включены лайки, комментарии, репосты, сохранения, охват и показы: они могут быть компонентами целевой метрики, что создаст утечку.
- K-Means сегментирует только этот набор по выбранным метрикам. Слабый silhouette означает, что кластеры не следует представлять как устойчивые классы «вирусности».
- Данные описаны как синтетические, а лицензия Kaggle указана как неизвестная. Не обобщайте выводы на реальный Instagram и не публикуйте данные повторно без проверки лицензии.

## Проверенные ориентиры текущего набора

Официально скачанный CSV содержит 29 999 записей и 15 исходных полей; пропусков и дубликатов `post_id` не найдено. В текущем запуске:

- Welch ANOVA по форматам: `p≈0,635`; `η²≈0,000057`.
- Хи-квадрат для формата и терциля engagement rate: `p≈0,708`; `V Крамера≈0,008`.
- Spearman для длины подписи и числа хэштегов: rho около 0,005 и 0,004 соответственно.
- Квадратичный Wald-тест для подписи и хэштегов: `p≈0,240`.
- Хронологический test: baseline MAE около 9,30; линейная модель около 9,30; Random Forest около 9,38; значения R² отрицательные.
- K-Means: лучший silhouette среди проверенных k равен примерно 0,275 при `k=2`.

Эти числа — ориентиры для сверки. При другой версии файла результаты пересчитать и обновить слайды. Итоговые таблицы и графики из текущего запуска находятся в `results/`.
